# Bootstrap import feature controls

The selected change adds common `HAVE_STRFTIME=1` and test-profile-only
`HAVE_WAITPID=1`/`HAVE_SYS_WAIT_H=1`. `HAVE_WCSFTIME` remains undefined.
The existing test-only `HAVE_FORK` layout contract remains mandatory.
No frozen test ID, decorator, required case or exclusion changes.

`header_contract.c` measures actual upstream interpreter/runtime layouts using
the selected target policy and shared headers. It calls typed real formatter and
wait service pointers, checks LP64/unsigned16 wchar, status decoders and untouched
wait output. Native controls define `IMPORT_NATIVE_ORACLE` to distinguish native
no-child ECHILD from the managed service's unsupported-process EPERM. Neither
control creates a child or supplies an interpreter/service implementation.

Native layout compilation must use the actual DotCC headers, `-nostdinc`,
`-fshort-wchar`, DotCC identity with GCC identity undefined, and the retained
`ForkHooks/native_layout_syntax.h` parser bindings. Native glibc's pthread and
wide-character layouts are not the selected target ABI. The formatter only
passes back the opaque native `gmtime` pointer; it does not inspect its fields.

`test_policy.py` checks common/per-unit split and glued D/U overrides, complete
wait selection, header agreement, defined-zero rejection and absent wide service.
The source-selected API inventory must also inspect the actual unchanged
timemodule, posixmodule/Clinic and _testcapimodule object emissions. These narrow
controls do not establish interpreter imports or upstream assertion success.

Every build/emission/native command requires the coordinator's explicit slot and
the appropriate per-command shared/native flock. Whole286 and whole193 generation
are separate grants after full byte preservation. Full actual-product and
consumer-input D10, ABI, interpreter matrices and P6 evidence remain required.

## Hostname selection and current control entrypoints

Only `upstream-tests-static` adds `HAVE_GETHOSTNAME=1`. Common GETPID/STRFTIME,
embedded selection and the rejected-process contract remain unchanged.
`test_gethostname_policy.py` protects both selected/unselected profiles against
common/unit split/glued D/U, defined-zero and header disagreement. Run the four
pure scripts with Python `-B`; together they contain31 tests. A16 retains the
original resolver's failing hostname-test execution separately.

`hostname_header_contract.c` measures actual core layouts before/after and
includes `hostname_services.c`. The real shared hostname fixture checks typed
direct/function-pointer calls, exact independently supplied host identity,
truncation/NUL/sentinels, preserved errno, LP64 and unsigned16 wchar. The launcher
reads `/proc/sys/kernel/hostname`; a wrong expected name must exit25. These
fixtures supply no interpreter or replacement service. `identity_services.c`
retains the preceding getpid/formatter/wait/status checks.

A16's private command plans/results are under
`artifacts/owner-a-r16-20261018/`. They pass eight hostname and eight prior-service
raw/processed JIT/AOT cells with fresh actual-input bindings. Actual socketmodule
object emissions select only its existing guarded wrapper/doc/method entry.
Source/header/service controls do not qualify full interpreter imports, layout,
D10, ABI or upstream assertions. Whole286 and193/P6 remain separately granted
work; do not rerun a build plan without the coordinator's active serial grant.
