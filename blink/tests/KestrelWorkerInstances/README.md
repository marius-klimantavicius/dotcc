The genuine Kestrel static ELF and controlled native profile receipt identities
are fixed. Exactly six guest environment entries match that native witness:
LANG, the three recorded GC settings, immutable configuration without hot reload,
and diagnostics disabled. Normal Kestrel asynchronous socket transport remains
unchanged. Each public receipt is checked against its explicit expected hash,
authored/raw/final source manifests, producer objects, staged profile and compiler.
Workers compile from isolated copies of original authored sources and exact raw
or optimized generated bytes. No generated source repair or further translation
occurs here. The worker roots TranslatedBlink for NativeAOT.

Each of raw JIT, raw NativeAOT, optimized JIT and optimized NativeAOT uses four
actual worker processes and ten HTTP comparisons:

- A and B run simultaneously at guest port 8080, with distinct executable paths,
  process IDs and published loopback endpoints. A handles health, padded health,
  fragmented health, missing path and normal HTTP stop. B serves health both
  before and after A stops, then receives ordinary cooperative owner stop.
- A restarts in a fresh process, serves health and completes normal HTTP stop.
- A fourth worker serves health and remains idle until its own ordinary deadline.
  Its actual startup/health must leave at least five seconds before the reserved
  worker deadline, and at least one second of subsequent idle wait is observed.

The additional per-image marker files are mounted and hashed but **not read by
the guest**. This qualifies observed executable paths, independent worker state
and endpoints; it does not claim arbitrary guest filesystem-content isolation.

The native 3,592-byte padded request is also sent in seven consecutive writes,
ending at offsets 1, 17, 59, 571, 1595, 3591 and 3592. Write boundaries do not
claim TCP packet boundaries. Actual status/reason, all response headers and body
match native semantics, excluding only the value of a syntactically valid real
RFC1123 Date header. Raw responses remain artifacts. The C# comparator is derived
from the standalone Kestrel gate; the runner independently verifies saved
responses with the frozen native producer's parser.
