# Native boundary compromises

No boundary compromise has been accepted as implemented behavior. Pending signal,
post-fork, compiler-intrinsic, variadic, imported-data and aggregate-ABI questions
remain blockers, as described in `PLAN.md` and `blockers.md`.

For each implemented compromise record original source/symbol/native behavior,
observed obstacle, chosen replacement, differences, affected targets/forms/modes,
reproducible native/emitted evidence and possible removal. Compiler fixes that
restore C semantics are not libuv algorithm replacements.
